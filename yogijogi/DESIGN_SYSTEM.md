# YogiJogi Design System

요기조기의 화면과 컴포넌트에서 공통으로 사용할 색상, 타이포그래피, 간격 기준을 정리한다. 요기조기는 지도와 장소 정보를 중심으로 하므로, 지도 자체를 가리지 않으면서 경로·장소·제보 상태를 빠르게 구분할 수 있어야 한다.

## 1. 디자인 원칙

- **지도 우선:** 지도와 경로가 화면의 중심이다. 카드, 필터, 버튼은 지도 정보를 가리지 않도록 배치한다.
- **친근하지만 명료하게:** 둥근 형태와 부드러운 색을 사용하되, 정보의 우선순위와 가독성을 먼저 지킨다.
- **색상에만 의존하지 않기:** 장소·제보 유형과 상태는 색상뿐 아니라 아이콘, 라벨, 텍스트로 함께 구분한다.
- **학교별 테마 지원:** 각 학교의 상징색은 브랜드 강조 색에 적용하고, 위험·행사·처리 상태를 나타내는 의미 색상은 학교가 바뀌어도 유지한다.

## 2. 컬러 팔레트

### 브랜드 및 기본 색상

| 토큰 | HEX | 용도 |
|---|---|---|
| `brand` | `#696FB8` | 브랜드 기본색, 선택된 하단 메뉴, 주요 아이콘 |
| `brandStrong` | `#50569A` | 주요 버튼, 강조 텍스트, 진한 브랜드 강조 |
| `brandSoft` | `#ECECF8` | 선택된 필터 배경, 보조 강조 영역 |
| `accentMint` | `#9CCDBB` | 보조 포인트, 완료·긍정 상태의 보조 표현 |
| `accentCoral` | `#F29A8C` | 따뜻한 포인트, 주의가 필요한 보조 강조 |
| `background` | `#F7F8FC` | 앱 기본 배경 |
| `surface` | `#FFFFFF` | 카드, 검색창, 바텀시트 |
| `textPrimary` | `#1B2438` | 제목과 본문 |
| `textSecondary` | `#737D92` | 설명, 보조 정보, 비활성 텍스트 |
| `border` | `#E3E6EF` | 카드·입력창 테두리와 구분선 |

### 정보 유형 및 상태 색상

아래 의미 색상은 브랜드 테마가 바뀌어도 동일하게 유지한다. 제보의 사실 여부나 긴급도를 색상만으로 단정하지 말고 상태 텍스트를 함께 표시한다.

| 의미 | HEX 제안 | 표시 예시 |
|---|---|---|
| 바퀴벌레·위험 제보 | `#D95757` | 최근 목격 핀, 주의 배지 |
| 흡연·연기 제보 | `#E8894A` | 흡연 제보 핀 |
| 행사 | `#568F83` | 행사 핀, 행사 카테고리 |
| 시설 확인·완료 | `#4F8A70` | 담당자 확인 또는 조치 완료 상태 |
| 일반 장소·정보 | `#737D92` | 기본 장소 핀, 미분류 정보 |

### 색상 적용 규칙

- 기본 화면은 `background`와 `surface`를 중심으로 구성하고, 지도 위 UI는 흰색 카드·칩으로 분리한다.
- 주요 버튼은 `brandStrong` 배경과 흰색 텍스트를 기본으로 한다. 브랜드 기본색은 내비게이션 선택 상태나 아이콘에 사용한다.
- 선택된 필터는 브랜드 계열로 표시한다. 선택 상태를 빨간 테두리로 나타내지 않는다. 빨강은 실제 위험 제보에 남겨둔다.
- `accentMint`와 `accentCoral`은 작은 포인트나 보조 배지에 사용한다. 넓은 배경에 사용할 때는 텍스트 대비를 확인한다.
- 지도 핀과 경로선은 서로 구분하고, 핀이 많을 때는 클러스터 또는 필터를 사용해 지도 가독성을 유지한다.
- 학생 제보와 담당자가 확인한 정보는 색상만으로 구분하지 않고 `학생 제보`, `담당자 확인` 같은 라벨을 함께 표시한다.

## 3. 학교별 테마

학교별 테마는 브랜드 토큰만 교체하는 방식으로 적용한다.

| 공통 토큰 | 성신여자대학교 기본값 | 학교별 변경 |
|---|---|---|
| `brand` | `#696FB8` | 가능 |
| `brandStrong` | `#50569A` | 가능 |
| `brandSoft` | `#ECECF8` | 가능 |
| 의미 색상 | 위 정보 유형 표 | 변경하지 않음 |
| 중립 색상·본문 색상 | 위 기본 팔레트 | 특별한 접근성 검토 없이 변경하지 않음 |

학교 상징색이 너무 밝거나 어두우면 그대로 버튼 배경으로 쓰지 않는다. 텍스트 대비를 확보할 수 있도록 진한 강조색과 연한 배경색을 별도로 지정한다.

## 4. 타이포그래피

- 기본 서체: **Pretendard**
- 화면에서 사용할 기본 굵기: **Bold, Medium, Light**

| 스타일 | 크기 | 굵기 | 용도 |
|---|---:|---|---|
| `title` | 18px | Bold | 화면 제목, 장소명, 주요 정보 |
| `body` | 14px | Medium | 본문, 버튼, 필터, 카드 제목 |
| `caption` | 12px | Light | 제보 시각, 보조 설명, 업데이트 시각 |

- 폰트 크기는 우선 4px 단위로 조정한다. 적절한 크기가 나오지 않을 때는 2px 단위 조정을 허용한다.
- 한 화면 안에서 폰트 크기와 굵기 사용을 일관되게 유지한다.
- 지도 위 텍스트는 배경과 충분한 대비를 확보한다. 지도 이미지 위에 직접 작은 글자를 얹기보다 카드나 배지를 사용한다.
- 실제 Flutter 프로젝트에서 Pretendard 폰트 파일을 추가한 뒤 각 굵기를 올바르게 매핑한다. 폰트 파일이 준비되지 않은 개발 환경에서는 시스템 기본 글꼴을 사용한다.

## 5. 간격 및 레이아웃

### 기본 기준

| 토큰 | 값 | 용도 |
|---|---:|---|
| `screenPadding` | 16px | 화면 좌우 기본 여백 |
| `elementGapHorizontal` | 10px | 나란히 놓인 객체 사이 좌우 간격 |
| `spacingUnit` | 4px | 컴포넌트 내부·세로 간격의 기본 단위 |

- 간격은 기본적으로 4px 단위로 조정한다. 필요하면 2px 단위로 줄여 맞춘다.
- 컴포넌트 간 세로 간격은 8px, 12px, 16px, 24px처럼 4px 배수 사용을 우선한다.
- 화면 가장자리의 주요 콘텐츠는 좌우 16px 여백 안에 정렬한다.
- 가로로 나열되는 버튼·칩은 기본적으로 10px 간격을 둔다. 화면 폭이 좁으면 줄바꿈 또는 가로 스크롤을 고려한다.
- 지도 화면의 검색창, 필터, 위치 버튼은 지도 조작을 방해하지 않도록 여백과 겹침을 확인한다.

## 6. 컴포넌트 기준

### 버튼

- 주요 행동에는 `brandStrong` 버튼을 사용한다.
- 보조 행동에는 흰색 또는 `brandSoft` 배경을 사용한다.
- 버튼 텍스트는 `body` 스타일을 기본으로 한다.
- 선택 상태와 위험 상태를 혼동하지 않도록, 일반 선택 버튼에는 위험 색상을 쓰지 않는다.

### 검색창과 필터

- 검색창은 `surface` 배경, `textSecondary` 안내 문구, `brand` 검색 아이콘을 기본으로 한다.
- 필터가 선택되면 브랜드 계열로 명확하게 표시한다.
- `전체`, `빈 강의실`, `행사`, `벌레 주의` 등 서로 다른 종류의 필터는 의미가 겹치지 않도록 라벨과 아이콘을 함께 쓴다.

### 카드와 바텀시트

- 장소·행사·제보 상세는 카드 또는 바텀시트에서 확인한다.
- 카드에는 제목, 위치, 기준 시각, 출처 또는 처리 상태를 우선 배치한다.
- 지도 위 카드가 화면을 과도하게 덮지 않도록 정보를 요약하고, 상세 정보는 확장 화면으로 제공한다.

### 지도 핀과 경로

- 장소, 행사, 바퀴벌레, 흡연, 시설 문제 핀은 각기 다른 아이콘과 색으로 구분한다.
- 경로 옵션의 선택 상태는 브랜드 색으로 표시하고, 경로 주변 제보 색과 혼동되지 않게 한다.
- 핀을 누르면 해당 위치의 상세 카드가 열리며, 카드와 지도 핀의 선택 상태를 동기화한다.

### 하단 내비게이션

- 선택된 메뉴는 브랜드 색, 비선택 메뉴는 `textSecondary`를 사용한다.
- 아이콘과 텍스트를 함께 표시한다.
- 지도 화면의 콘텐츠가 하단 내비게이션에 가려지지 않도록 안전 여백을 둔다.

## 7. Flutter 색상 토큰 예시

색상 값은 앱 전체에서 직접 반복 입력하지 말고 한 곳에 모아 관리한다.

```dart
import 'package:flutter/material.dart';

abstract final class AppColors {
  static const brand = Color(0xFF696FB8);
  static const brandStrong = Color(0xFF50569A);
  static const brandSoft = Color(0xFFECECF8);
  static const accentMint = Color(0xFF9CCDBB);
  static const accentCoral = Color(0xFFF29A8C);
  static const background = Color(0xFFF7F8FC);
  static const surface = Color(0xFFFFFFFF);
  static const textPrimary = Color(0xFF1B2438);
  static const textSecondary = Color(0xFF737D92);
  static const border = Color(0xFFE3E6EF);

  static const hazard = Color(0xFFD95757);
  static const smoking = Color(0xFFE8894A);
  static const event = Color(0xFF568F83);
  static const resolved = Color(0xFF4F8A70);
}
```

학교별 테마 기능을 구현할 때는 `brand`, `brandStrong`, `brandSoft`를 학교 설정에서 주입하고, 나머지 의미 색상은 공통 토큰으로 유지한다.

## 8. 적용 전 확인

- 텍스트와 배경의 대비가 충분한지 확인한다.
- 색각 차이가 있어도 아이콘·라벨·상태 문구로 정보를 구분할 수 있는지 확인한다.
- 지도 이미지가 밝거나 복잡한 구간에서도 버튼·핀·텍스트가 읽히는지 확인한다.
- 제보의 색상은 제보 상태와 신뢰도를 과장하지 않는지 확인한다.
- 실제 화면 크기에서 16px 화면 여백과 10px 가로 간격이 답답하지 않은지 확인한다.
